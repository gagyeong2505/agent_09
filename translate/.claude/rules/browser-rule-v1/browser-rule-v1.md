# 브라우저 제어 규칙 (v1)

이 규칙은 이 프로젝트에서 웹 브라우저를 열거나 제어할 수 있는 작업(페이지 이동, 클릭, 입력, 스크린샷, 페이지 내용·이미지 수집)이 있을 때마다 적용됩니다.

## 1. 자동 호출 (트리거 키워드)

- 사용자 메시지에 브라우저 제어 키워드가 있으면 동의를 묻지 않고 바로 Playwright MCP(`mcp__playwright__*`)를 호출합니다.
- 트리거 키워드 (비슷한 표현과 영어 표현 포함):
  - "브라우저를 열어서", "브라우저로", "브라우저 열고"
  - "웹 제어", "웹에서 직접", "사이트에 접속해서", "들어가서"
  - "직접 작업", "직접 해줘", "직접 확인"
  - "클릭해줘", "입력해줘", "스크린샷 찍어줘"
  - "open the browser", "control the web", "do it directly", "take a screenshot"

## 2. 동의 후 호출 (키워드 없음)

- 메시지에 트리거 키워드가 없어도 Playwright MCP로 하면 더 잘할 수 있는 작업이라면, 호출하기 전에 사용자에게 먼저 동의를 구합니다. 예:
  - 로그인이 필요하거나 내용을 동적으로(JavaScript) 그리는 페이지
  - 자료조사나 포스팅용 이미지·스크린샷 수집
  - 페이지가 실제로 어떻게 보이고 동작하는지 확인
- 브라우저가 왜 필요한지와 무엇을 할지 한두 줄로 설명한 뒤 답을 기다립니다.
- 동의는 해당 작업에만 적용되며, 다음 작업에는 다시 묻습니다.
- 사용자가 거절하면 다른 방법(WebSearch, WebFetch 등)을 쓰거나 한계를 보고합니다.

## 3. 도구 우선순위

- 기본 브라우저 도구로 Playwright MCP를 사용합니다.
- Claude in Chrome(`mcp__claude-in-chrome__*`)은 사용자가 명시적으로 지정할 때만 사용합니다.

## 4. 안전 수칙

- 트리거 키워드로 시작한 작업이라도 결제, 게시글 등록, 메시지·메일 발송, 삭제, 양식 제출처럼 되돌리기 어렵거나 외부에 영향을 주는 동작은 실행 직전에 다시 확인받습니다.
- 비밀번호 등 로그인 정보는 직접 입력하지 않고, 사용자가 브라우저에서 입력하게 합니다.
- 작업이 끝나면 브라우저를 닫습니다(`browser_close`).
- 스크린샷과 수집한 파일은 프로젝트 루트가 아닌 용도별 폴더(예: `research/images/<주제>/`)에 저장합니다. `.playwright-mcp/` 폴더는 git 제외 대상이며 임시 출력용으로만 씁니다.
